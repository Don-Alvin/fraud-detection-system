# IEEE-CIS Fraud Detection Dataset

## Source
Platform: Kaggle
URL: https://www.kaggle.com/competitions/ieee-fraud-detection/data

## Files Structure

### Transaction Data
- Contains transaction details, amount, product info, time
- `train_transaction.csv`: 590,540 rows * 394 columns
- `test_transaction.csv`: 506,691 rows * 393 columns

### Identity Data
- Contains network info, device type, digital signature
- `train_identity.csv`: 144,233 rows * 41 columns
- `test_identity.csv`: 141,907 rows * 41 columns
